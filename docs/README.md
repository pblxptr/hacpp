# hacpp documentation

This directory contains short, practical notes for using the public API.

- [Client lifecycle](client-lifecycle.md): connecting clients, running receive loops, and choosing unique or shared clients.
- [Entities](entities.md): creating sensors, buttons, covers, setup, state updates, and command handlers.
- [Errors and reconnect](errors-and-reconnect.md): how errors are reported and how reconnect recovery works.

The library is still early, so these pages describe the current API shape rather than a frozen long-term contract.
